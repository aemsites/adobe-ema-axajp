# Block map — www.axa.co.jp replica → EDS (rollout phase B)

28 page blocks (17 shared + 11 template-specific). These ids are recorded in each archetype's `stardust/migrated/**/_meta.json` `modules[]`; `blocks.json` and `plan.json` are built from them. Prototypes are in `stardust/prototypes/`. "canon" means `canon/canon.css`.

## Not blocks
- **Chrome / foundation** (header, footer, CTA rail `.cta-rail`, back-to-top `.back-to-top` / `.ai-pagetop`, `canon/chrome.js`) is handled by the foundation as `/nav` and `/footer` documents. Recruitment has its own chrome (`.rc-header`, `.rc-footer` in recruitment.css), so it needs separate nav/footer documents selected by page metadata (`nav` / `footer`). These are not page blocks.
- **Default content**: headings, text, images, `<hr>`, CTA buttons (`.btn`/`.btn-row`, `.hp-btn--primary|secondary`, `.btn2`, `.db`, `.ai-list-btn`, `.p-btn-wrap`), `.bold-link`/`.custom-link` arrow links, `.note-list` (※), `.verification` code, prospect `.p-sub` lead, company `.slice-heading`/`.slice-text`/`.slice-rule`. Express variants as button emphasis (`strong` = primary, `em` = secondary) plus section styles. Do not express them as block classes.
- **Section styles** (section-metadata `style`), not blocks: `light-band` (index), `band` with `--band-bg`/`--band-img` (content.css `.band-outer`: background colour and image as section-metadata keys), `bordered-title` (content.css `.slice-heading__text--bordered`, customer `.bordered-title`), `kv` (recruitment `.rc-kv`, a full-bleed image), `full-sp` (`.page-layout--full-sp`).
- **Page-type base**: the content type (company and its siblings) uses a 14px/1.4 body and a chrome back-port (notes-company.md). Set this with template metadata (`template: content`, a body class), not with a block.

## Catalogue

EW = deploy editability contract. All blocks node-slot: they MOVE authored `h*/p/ul/picture` (EW1), style through wrapper descendants (EW2), move CTAs as their `<p>` (EW3), never put authored text in `<button>`/`<summary>` (EW7), and keep `decorate()` re-entrant (EW9). PC/SP twins: author ONE node. Build the second presentational copy in JS with `stripInstrumentation()` (EW4), or use CSS line breaks (`br.sp-br`) where only the wrapping differs.

## Plan facts (plan.mjs)
- Conversion points: company converts art-image, anchor-links, columns, breadcrumbs. About-insurance converts section-title, bubble-guide, accordion, link-list, testimonial-cards, entry-links, contact-links. Customer converts page-banner, banner-slider, link-panels, link-buttons, feature-grid, news-list. Index converts hero-carousel, product-cards, simulation-quiz, cta-consult, strengths, banner-links.
